# 寻找爱弥斯（Find Aemeath）

寻找爱弥斯是移动端优先的观察推理游戏。玩家在彩色区域棋盘中标记或翻开格子，在生命耗尽前找出全部目标。当前规则速查见 [规则摘要](docs/rules-summary.md)。

## 棋盘规则

- 棋盘为方形，区域数与边长相同；每格属于一个 4 连通颜色区域。
- 每个区域、每行和每列恰好有一个目标。
- 任意两个目标不同行、不同列，且不处于彼此八邻域内。
- 区域覆盖全部棋盘，区域邻接图连通；3 格及以上区域必须同时跨越多行和多列。生成器会让每个区域至少包含两个格，避免出现固定的单格必答题。
- 颜色用于区分区域，不承载唯一状态信息。

生成器使用确定性种子。关卡只有同时通过结构校验、目标约束、唯一解枚举和完整推理链校验才会被采用；求解器只读取可见的区域形状，不读取隐藏答案。

## 推理规则

- 每个区域、行和列都只能放置一个目标；选定目标后，同区域、同行、同列及八邻域候选都会被排除。
- 行/列锁定：如果一个区域的全部候选都在同一行（或列），该行（或列）由它占用，其他区域不能再使用这条线。
- 隐藏单：如果一行（或列）的候选只来自一个区域，该区域必须占用这条线，并排除它在其他线上的候选。
- 集合占用规则：如果两个或多个区域的所有候选只分布在同样数量的行（或列）内，这些行（或列）必然分别被这些区域占用，其他区域在这些行（或列）中的候选可以排除。例如两个颜色区域都只跨越两行时，这两行的其他颜色不会再有正确格。
- 生成器会保留至少包含高级推理步骤的唯一解：普通关至少一次，困难关至少两次；并避免把任何区域固定生成为单格。

## 操作

| 格子状态 | 单击 | 双击 |
| --- | --- | --- |
| 未探索 | 标记 X | 翻开并判定 |
| 玩家标记 | 取消标记 | 无效 |
| 自动标记 | 无效 | 无效 |
| 已揭示 | 保持状态 | 保持状态 |

- 单击延迟 300 ms，以等待浏览器 `dblclick`；同一格连续两次 `Enter`/`Space` 也可翻开。
- 翻开目标会显示图标；翻开空格会保留错误标记并扣 1 条生命，同一格不会重复扣血。
- 每关 3 条生命。找齐目标即成功；生命归零且仍有目标时失败。
- 用时只作统计，没有关卡时限。
- “目标提示”会将第一个未揭示目标高亮 1.5 秒，当前没有次数限制。
- `P` 或 `Escape` 暂停/恢复；暂停和动画期间禁止棋盘输入。

## 自动标记

自动标记默认关闭。打开设置面板中的开关后，找到目标时系统把被该目标直接排除的未探索格改为自动标记：同一区域、同行、同列及八邻域。它不读取其他隐藏目标，不扣生命，也不覆盖玩家已有标记。

“手动标记”会根据所有已发现目标，将仍未探索且可排除的格子改为玩家标记；它不受自动标记开关影响，也不覆盖已有标记。“清除标记”只清除玩家标记。关闭自动标记后，新找到的目标不会修改其他格子。

## 关卡进度

| 周期位置 | 难度 | 棋盘/区域 |
| --- | --- | --- |
| 第 1-2 关 | 普通 | `8 x 8` / 8 |
| 第 3-4 关 | 普通 | `9 x 9` / 9 |
| 第 5 关 | 困难 | 从 `10 x 10` / 10 起，随周期增至 14 |

每 5 关重复 4 个普通关卡和 1 个困难关卡。重试保持同一关卡与布局，下一关才切换种子。

## 状态与页面

```text
platform -> playing <-> paused
playing -> success -> playing（下一关）
playing -> failed -> playing（重试）
playing -> platform
```

Pinia store 统一维护关卡、格子、生命、累计用时、输入锁和设置。平台首页负责题图、进度和已解锁关卡选择；游戏应用包含游戏页、暂停层、结果页和设置面板。

## 持久化与设置

`localStorage` 键 `find-aemeath:v1:progress` 保存当前关卡、最高进度、自动标记、音效、主题以及背景/图标资源 ID。运行中的格子状态和累计用时不会恢复；存储写入失败时游戏仍可继续。

平台通过 `/games/find-aemeath/game?level=<index>` 直达所选关卡；游戏根路径进入保存的当前进度。超出已解锁范围的关卡参数会被限制到最高可玩关卡。

当前只有一套默认背景和目标图标。主题支持深色、浅色和高对比度；重置进度需确认，并只清除本游戏数据。

## 无障碍边界

- 每格是带可读名称的可聚焦按钮，支持 Tab、`Enter` 和 `Space`。
- 支持 `prefers-reduced-motion` 和高对比度主题。
- 当前未实现方向键移动焦点，生命、计时和错误信息也未全部接入 `aria-live`。
- 触摸双击仅完成了移动视口自动化测试，仍需真实设备验证系统手势影响。

## 部署与验证

- 应用基路径为 `/games/find-aemeath/`，由整站 Web 服务代理。
- Nginx 提供 SPA history fallback、`/healthz` 和静态资源缓存。
- `npm run check` 覆盖规则单测、类型检查/构建和 Playwright；按仓库约定在容器中运行。
- 核心验收包括确定性生成、唯一解、完整推理链、标记/翻开/扣血、自动标记、暂停、进度恢复和多尺寸布局。
